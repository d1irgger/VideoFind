VideoFind – 视频检索器
一款基于 Python + CustomTkinter 的桌面工具，用于批量扫描视频文件，读取 Windows 文件属性中的“标题”字段，自动提取其中的网址链接，并支持快速播放、搜索、分页与导出。界面采用 iOS 风格设计，简洁高效。

✨ 主要功能
📁 文件夹扫描 – 选择视频文件夹，自动递归（可选）扫描所有支持的视频格式（mp4, mov, mkv, avi, flv, webm, wmv, mpg, mpeg）。

🔗 智能链接提取 – 读取视频文件的 Windows“标题”属性，使用正则提取完整 URL、www. 域名或普通域名（如 bilibili.com），并自动补全协议。

▶️ 本地播放 – 点击“本地”按钮，默认使用系统默认播放器打开视频；也可在设置中切换为使用默认浏览器播放（支持 Chrome/Edge/Firefox 等）。

🌐 网页跳转 – 点击“网页”按钮，直接打开提取到的链接；若无链接，则使用文件名进行百度搜索。

🔍 实时搜索 – 在搜索框中输入文件名关键字（支持单字），列表实时过滤，不区分大小写。

📃 分页浏览 – 每页固定显示 7 个视频，支持首页、上一页、下一页、末页导航。

⚙️ 设置选项 – 可切换是否扫描子文件夹，以及是否使用浏览器播放视频。

📤 导出链接 – 一键将所有视频的文件名与对应链接（若无则写“无链接”）导出为 log.txt，并用浏览器自动打开。

🎨 iOS 风格 UI – 浅色/深色自适应，卡片列表、圆角按钮、居中分页栏，操作直观。

🚀 安装与运行
环境要求
Python 3.8+

Windows 操作系统（标题读取依赖 Windows Shell API）

安装依赖
bash
pip install customtkinter opencv-python pillow pywin32
启动程序
bash
python video_finder.py
🧰 使用说明
点击 “选择文件夹” 按钮，选取包含视频的目录。

程序自动扫描并解析视频，列表按文件名数字从小到大排序（自然排序）。

每个视频卡片显示：

文件名（加粗）

分辨率、时长、大小、修改时间

提取的链接（若无则显示“无链接”）

“本地” 按钮 – 打开视频（播放方式由设置决定）

“网页” 按钮 – 打开链接或执行搜索

使用搜索框快速筛选。

底部导航栏进行分页切换。

进入 “设置” 页面，可调整：

扫描子文件夹（开启/关闭）

使用浏览器播放（开启/关闭）

点击 “导出链接”，生成 log.txt 并自动在浏览器中打开。

⚙️ 技术细节
UI 框架 – customtkinter (现代 Tkinter 扩展)

视频信息解析 – OpenCV (获取分辨率、时长、帧率等)

文件属性读取 – pywin32 (调用 Windows Shell API 读取“标题”字段)

链接提取 – 正则表达式 (re) 匹配多种 URL 格式

自然排序 – 自定义密钥函数，实现数字从小到大排序

多线程 – 扫描过程不阻塞 UI 响应

跨平台考虑 – 仅 Windows 系统支持标题读取，其他系统跳过
