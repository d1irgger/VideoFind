🎬 VideoHub · 本地视频管理，如诗般优雅
极简 · 强大 · 天生为探索而生
用苹果式的直觉，管理你珍藏的每一帧记忆。

✨ 一眼惊艳 · 处处精致
🔍 即时搜索 — 输入即筛选，毫秒级响应，让海量视频变得触手可及。

🎞️ 智能解析 — 自动读取分辨率、时长、尺寸、修改时间，甚至 Windows 文件“标题”与隐藏链接，信息一目了然。

📦 批量扫描 — 多线程并发解析，即便千部影片，也能优雅加载。

🌐 内置服务器 — 一键启动本地 Web 服务，任何浏览器皆可访问，无需安装任何客户端。

📱 响应式设计 — 从桌面到移动设备，界面如流体般自适应，操作始终从容。

🔗 一键跳转 — 若视频文件包含网页链接（如下载来源），点击即可直达；若无，自动以文件名搜索 Bing，永不迷失。

📋 导出链接 — 一键生成 log.txt，包含文件名与关联链接，方便整理与分享。

🎨 原生玻璃态 UI — 毛玻璃、柔和阴影、灵动过渡，每一处细节都经精心打磨，仿佛 macOS 原生应用。

🚀 快速开始
bash
# 克隆仓库
git clone https://github.com/yourname/visionary-video-manager.git

# 安装依赖（仅需 OpenCV + pywin32）
pip install opencv-python pywin32

# 运行，默认端口 8000
python visionary.py
浏览器自动打开 http://localhost:8000，点击 浏览 选择视频文件夹，即刻开启你的视觉之旅。

🛠 技术内核 · 稳如磐石
OpenCV — 精准解析视频元数据

ThreadPoolExecutor — 多线程加速，榨干 CPU 性能

win32com — 深度集成 Windows Shell，提取高级属性

纯 Python HTTP 服务器 — 轻量自包含，无需额外 Web 容器

CSS 毛玻璃 + Flex 布局 — 纯前端美学，拒绝臃肿框架

💡 谁在用？
影音收藏家 — 整理本地电影、剧集、学习资料，快速检索

内容创作者 — 管理素材库，一键定位源文件

极客玩家 — 享受自托管的便利，随时随地通过浏览器访问
