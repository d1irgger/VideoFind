# 🎬 VideoHub

> 极简 · 强大 · 天生为探索而生  
> 用苹果式的直觉，管理你珍藏的每一帧记忆。

---

## ✨ 一眼惊艳 · 处处精致

- **即时搜索** — 输入即筛选，毫秒级响应，海量视频触手可及。
- **智能解析** — 自动读取分辨率、时长、尺寸、修改时间，甚至 Windows 文件“标题”与隐藏链接。
- **批量扫描** — 多线程并发，千部影片也能优雅加载。
- **内置 Web 服务器** — 一键启动，任何浏览器均可访问，无需安装客户端。
- **响应式设计** — 从桌面到手机，界面如流体般自适应。
- **一键跳转** — 有链接直达来源，无链接自动以文件名搜索 Bing。
- **导出清单** — 一键生成 `log.txt`，方便整理与分享。
- **玻璃态 UI** — 毛玻璃、柔和阴影、灵动过渡，宛如 macOS 原生。
