# 视频搜索

**简洁。快速。优雅。**

一个为本地视频而生的轻量检索工具。  
以苹果设计语言重新构建，将强大功能藏于极简体验之中。

---

### 设计理念

告别复杂的桌面窗口，回归浏览器本身。  
启动即用，无需额外界面框架，一切交互都在你熟悉的网页中完成。

毛玻璃质感、系统级动效、高刷新率适配，  
每一个细节都追求「刚刚好」的流畅与克制。

---

### 核心特性

**极速扫描**  
多线程并行解析视频元数据，即使面对数百个文件，也能保持轻快响应。

**智能分页**  
当文件数量增多时，自动启用省略号分页，始终清晰可控。

**原生质感**  
遵循苹果设计规范：系统蓝、系统绿、精确的字重与间距、细腻的过渡动画。

**一键直达**  
自动读取 Windows 文件标题属性，提取其中的链接，或快速跳转搜索。

**灵活播放**  
支持系统默认播放器或浏览器内播放，随心切换。
